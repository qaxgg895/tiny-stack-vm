# Tiny Stack VM

[![make.fun](https://make.fun/badge.svg)](https://make.fun/c/tiny-stack-vm-01-run-20261122)

A faithful interpreter of make.fun's tiny stack ISA v1 (Node 22, no
dependencies). Run `node main.ts`: it reads every `/input/<id>/program.bin`
+ `input.bin` and writes `/output/<id>/stdout.bin` and `exit.txt`.
